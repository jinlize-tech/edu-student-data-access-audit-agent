# JLZ-EDU-AG-033 Codex执行任务书

## 1. 基线

- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`
- 候选来源：`CAND-052`
- 正式产品：`JLZ-EDU-AG-033` / 学员数据地图与权限审计
- 类型：Agent
- 批次：1
- 业务中心：15 数字治理与AI合规中心
- 版本基线：`EDUCATION_BASELINE_V1.0.0`
- 产品版本：`1.0.0`

## 2. 用户、痛点与目标

- 用户：校长、数据/IT负责人、教务、市场、客服、系统管理员
- 痛点：学生和家长数据散落在表单、微信、CRM、教务系统和表格中，谁能访问、保留多久、流向何处常不清楚。
- 目标：盘点数据字段、系统、流程、角色与供应商，建立数据地图和最小权限建议，优先处理高风险访问。

## 3. 输入契约

## 4. 工作流

1. 定义范围
2. 盘点字段与系统
3. 映射流程和角色
4. 识别敏感/未成年人数据
5. 权限差距
6. 整改与复核

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点系统与表格清单、字段字典、用户角色、业务流程、共享方式、供应商、保留策略、现有权限，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕盘点数据字段、系统、流程、角色与供应商，建立数据地图和最小权限建议，优先处理高风险访问。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按定义范围 → 盘点字段与系统 → 映射流程和角色 → 识别敏感/未成年人数据 → 权限差距 → 整改与复核设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由数据负责人/IT/法务复核学生数据字段、访问权限、供应商、日志和删除。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `学员数据地图`
- `权限矩阵`
- `整改优先级`

## 7. 差异化与排重

- 与现有产品：隐私影响评估针对一个项目；本产品是组织级数据地图和权限治理，不处理单笔业务。
- 排重检查：部分重叠；共享数据主体和角色，但本产品输出全局数据流和访问审计。
- 独立理由：提供字段/角色清单即可独立审计，不依赖任何业务系统连接。

## 8. 安全与人工门禁

- 复核角色：数据负责人/IT/法务
- 复核范围：学生数据字段、访问权限、供应商、日志和删除
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
